# Ionirix Emergent-UI Onboarding

Runnable scaffold for the Emergent-UI onboarding architecture defined in the Ionirix onboarding workspace plan.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run test`

Open `../ionirix-emergent-ui.code-workspace` in VS Code to work with the architecture-specific folders.
