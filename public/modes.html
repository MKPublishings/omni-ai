Cognitive Modes

Switch cognitive lenses instantly. Each mode optimizes reasoning, language, and output for specific domains.

🧭

Auto

Intent-aware mode routing across all cognitive profiles

Overview

Auto mode acts as the router profile. It infers user intent from the latest prompt and routes to the most suitable mode (architect, analyst, visual, lore, reasoning, coding, knowledge, system knowledge, anatomy, simulation, cosmic, multiverse, or environment) while preserving stable conversation flow.

Core Features

  • 🧠
    Intent Detection

    Detects whether the user asks for planning, coding, research, simulation, or creative output

  • 🔀
    Dynamic Routing

    Selects the best cognitive mode per request while keeping context continuity

  • ⚖️
    Balanced Defaults

    Uses safe, practical defaults when intent confidence is mixed

  • 🛰️
    Transparent Behavior

    Pairs with model inspector metadata so routing decisions stay inspectable

Technical Stack

Reasoning Style Intent classification + adaptive handoff
Output Format Mode-appropriate responses
Language Tone Contextual and task-aware
Best For Mixed workloads and fast switching

Simulation

Contained reality engine for stateful system simulations

What It Is

Simulation Mode runs a contained cognitive environment inside ION. It tracks system state over steps, applies explicit rules, and emits logs for transitions. V1 defaults to a System-State simulator profile.

How It Works

  • 📏
    Rule Parsing

    Reads simulation rules and uses them as execution constraints

  • 🧩
    State Initialization

    Builds bounded state and entity context at simulation start

  • 🔁
    Step Execution

    Processes transitions in ordered, inspectable steps

  • 🪵
    Log Emission

    Outputs concise simulation logs and status metadata

Environment Mode

Mode #13 Planetary Scale v1.0

Environment Mode transforms Ionirix into a full-scope planetary simulation engine. It models Earth across seven spatial scales - from individual villages (1 km2) to the entire planet (510 million km2) - using ten coupled subsystems that exchange data every tick.

Seeded with real-world geography, demographics, climate zones, tectonic plates, and ocean currents, the simulation produces emergent behavior: droughts cascade into migration, trade disruptions ripple through economies, and governance adapts under pressure. Every layer is deterministic and reproducible via configurable RNG seeds.

🔬

Multi-Scale Resolution

Seven discrete scale levels (L0 Planet → L6 Village) with automatic cell generation, cross-scale propagation, and seamless zoom navigation.

🔗

Coupled Subsystems

Ten simulation systems execute in dependency-sorted order each tick. Climate drives hydrology; ecology feeds population; energy powers economy - fully connected.

🌐

Earth Seed Initialization

Pre-loaded with 7 continents, 10 countries, 50+ cities, 16 tectonic plates, 20 climate zones, and 10 ocean currents - all from real-world data.

⏩

Time Acceleration

Run simulations at 1x, 10x, 100x, or 1000x speed. Snapshot and rollback to any prior state. Deterministic replay with identical seeds.
